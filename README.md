Data Cleaning & Visualization Project

About

This project focuses on cleaning a raw sales dataset, handling missing values and duplicate records, and visualizing useful business insights.

Features

- Identifies missing values and duplicate rows
- Handles data quality issues
- Uses Pandas for data processing
- Uses Matplotlib for data visualization
- Analyzes sales by city and product

Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

Outcome

The project demonstrates how raw sales data can be cleaned, analyzed, and converted into meaningful visual insights.
